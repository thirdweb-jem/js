# What are Contracts?

Contracts offers an all-in-one toolkit for writing, building, deploying, and managing smart contracts.

### With the thirdweb Smart Contract toolkit, you can:

- Easily deploy custom or pre-built contracts to [any EVM network](https://thirdweb.com/chainlist)
- Deploy smart contracts in minutes with secure and audited [smart contract templates](https://portal.thirdweb.com/contracts/explore/overview).
- Use the deployment tool to [deploy any smart contract](https://portal.thirdweb.com/contracts/deploy/overview) directly from the thirdweb dashboard.
- Enable the [modular contract framework](https://portal.thirdweb.com/contracts/modular-contracts/overview) to add and upgrade functionalities for your app.
- Manage contract analytics, [decentralized data storage](https://portal.thirdweb.com/infrastructure/storage/overview) and set distribution mechanisms directly from the dashboard
